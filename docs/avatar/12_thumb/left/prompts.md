# Thumb - left

10 clips. Save each video in this folder, named exactly as the heading (e.g. `thumb_flexion_left_full.mp4`).
Use the reference image as both the first and the last frame. 25 fps.

## thumb_flexion_left_full
Thumb flexion (left) - Full

```
The patient smoothly holds the left hand up, palm facing the camera, and bends the thumb across the palm toward the little finger, through the full normal range, comfortably, face relaxed. Holds the end position for two seconds. Then slowly returns to the exact starting pose. The last frame must match the first frame exactly. Mouth closed and relaxed, no speaking. About 10 seconds long (at least 10 seconds), 25 fps, with the movement paced slowly to fill the time.
```
