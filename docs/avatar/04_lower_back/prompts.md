# Lower Back

12 clips. Save each video in this folder, named exactly as the heading (e.g. `lower_back_flexion_full.mp4`).
Use the reference image as both the first and the last frame. 25 fps.

## lower_back_flexion_full
Lower back flexion - Full

```
The patient smoothly stands and bends forward at the waist, reaching both hands down toward the toes, knees straight, through the full normal range, comfortably, face relaxed. Holds the end position for two seconds. Then slowly returns to the exact starting pose. The last frame must match the first frame exactly. Mouth closed and relaxed, no speaking. About 10 seconds long (at least 10 seconds), 25 fps, with the movement paced slowly to fill the time.
```

